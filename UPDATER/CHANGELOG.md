# Stream Suite Update Center Changelog

## 0.1.0 — MVP

### Added

- Desktop update interface with Stream Suite branding
- Installed, latest, and selected-version comparison
- Stable release checks through a public GitHub-hosted catalog
- Version Library for previous releases
- Update, reinstall, and downgrade states
- Prominent downgrade and data-compatibility warning
- Streamer.bot version and platform compatibility display
- Release notes and release-page links
- Verified HTTPS downloads from a fixed GitHub host allowlist
- Required SHA-256 and package-size verification
- Safe extraction into unique versioned folders
- ZIP traversal, symlink, duplicate-path, file-count, and expanded-size protection
- Setup-guide and `.sb` import discovery
- User-confirmed installed-version tracking
- Configurable download folder
- Creator-side release-catalog preparation helper
- GitHub Actions portable Windows build
- Automated core and security tests

### Deliberately excluded

- Silent Streamer.bot imports
- Direct edits to Streamer.bot's data directory
- Automatic configuration replacement
- Automatic data-schema downgrades
- Update Center self-updating
