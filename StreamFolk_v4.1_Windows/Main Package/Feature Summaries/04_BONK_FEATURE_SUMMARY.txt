🧠 PURPOSE

🔄 SYSTEM FLOW

STEP 1: READ COMMAND ARGUMENTS
--------------------------------

- Uses the self-bonk pool when no target is supplied or the invoker targets

- Uses the targeted bonk pool for another eligible attendee.

--------------------------------

user
